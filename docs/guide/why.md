# ModelBase 适合解决什么问题

ModelBase 适合把重复的接口字段处理集中到模型声明：名称映射、默认值、子模型创建、DTO 输出，
以及可选的编辑变更检测和还原。

## 适合

- 接口字段与 TypeScript 属性命名不同。
- 一个模型需要按多个业务场景输出字段。
- 编辑表单需要“是否修改、取消、保存基准”。
- 嵌套数据希望明确哪些节点是模型。
- Node 端统一 DTO 转换，同时能够关闭快照。

## 不应误解为

- ORM、数据库外键约束或自动持久化框架。
- 完整的运行时数据校验器。
- 自动支持任意对象图、循环引用和集合内部变更的深克隆系统。
- 无条件零内存/零开销的数据转换器。
- 与其他转换库逐项语义完全一致的替代品。

## 如何判断是否适合你的项目？

先用一份真实 DTO 跑通[快速上手](/guide/start/)，再测试嵌套、空值和编辑流程。
仅需少量字段拣选时，普通函数可能已足够；需要统一模型规则时再引入模型层。
class-transformer 迁移需阅读[差异评估](/guide/class-transformer/)，不能只凭装饰器名称判断兼容。
