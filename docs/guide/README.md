# 开发指南

ModelBase 将接口数据转换为有明确字段规则的模型，并提供序列化、变更查询和还原能力。
它不是 ORM，也不会替代输入校验或网络客户端。

## 第一次使用

从[学习路线](/guide/roadmap/)开始，按“创建 → 转换 → 编辑 → 嵌套 → 动态 → 集成”的顺序学习。
想先跑起来，可以直接阅读[快速上手](/guide/start/)。
