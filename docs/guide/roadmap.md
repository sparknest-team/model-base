# 学习路线

从“一个接口对象如何变成模型”开始，再引入状态管理。无需一开始理解 Proxy、元数据或缓存。

| 阶段 | 学习内容 | 完成后能做什么 |
|---|---|---|
| 1 · 入门 | [快速上手](/guide/start/)、[核心概念](/guide/know/) | 定义模型，接收 DTO，输出 DTO |
| 2 · 数据边界 | [字段映射与转换](/guide/mapping/) | 使用名称、默认值、转换回调和分组 |
| 3 · 编辑流程 | [变更、保存与还原](/guide/editing/) | 区分本地编辑、服务端回填和保存点 |
| 4 · 复杂结构 | [嵌套模型与集合](/guide/nested/) | 处理对象、数组、字典及主键匹配 |
| 5 · 动态结构 | [动态模型与列缓存](/guide/dynamic/) | 选择固定配置建模或数据驱动字段 |
| 6 · 应用集成 | [Node / Vue 3](/guide/integration/)、[service](/guide/service/) | 接入运行环境和请求流程 |
| 7 · 深入维护 | [API 速查](/guide/reference/)、[FAQ](/guide/faq/)、[迁移](/guide/migrate/) | 排查边界，维护已有项目 |

## 根据目标选择最短路径

- **仅转换接口数据**：阶段 1 → 2 → Node，创建时使用 `enableSnapshot: false`。
- **编辑表单并支持取消**：阶段 1 → 2 → 3 → Vue 3。
- **订单、树形数据和列表**：完成阶段 3 后阅读阶段 4。循环对象图不在自动支持范围内。
- **配置驱动页面**：先掌握普通模型，再阅读阶段 5；不要把所有模型都设为 `columnsInValue`。

## 怎么读示例？

连续教程使用同一组 User、Address、Item 模型，代码片段来自带断言的测试。
每章说明目标、输入、结果和边界；专题页面用于进一步查参数，而不是要求从头逐页阅读。
