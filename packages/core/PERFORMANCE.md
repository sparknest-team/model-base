# Node 端性能审计

## 注册驱动的列缓存

静态列注册统一管理，常态读取只检查注册时钟并返回已有计划；有注册发生时才解析继承依赖。更新、变更查询和内部主键取值不再为只读操作复制整套元数据。`getColumns()` 的公开副本语义、数据驱动列和自定义查询保持不变。

本轮复跑 `benchmark-lazy-snapshot.cjs`（Node v20.18.0，3 轮），lazy 初始化保留堆：scalar48 4.04 MiB、nested32 6.90 MiB、nested2 4.73 MiB；完整读取后分别为 6.06、13.03、5.98 MiB。旧保存点额外固定列计划引用，以保证后续注册不会改变旧快照规则。这是当前实现的测量，不是受控的前后收益比例，也不是峰值内存。

## 延迟状态精简（2026-09-23）

- 延迟读取改用共享函数，移除每实例的读取闭包与独立序列化参数对象；查询时才构造参数。
- 稳定列元数据共用键列表，捕获关系和重建视图不再反复分配模型列名数组。集合键仍实时读取。
- 保存点仍记录原存储归属，过滤数组仍防御性复制；不改变显式 DTO 覆盖、跨模块读取及父子保存点语义。
- 本轮没有改变主键数组匹配算法，也没有跳过深层节点检查；重复主键、自定义主键方法与回调执行顺序仍走原路径。

Node v20.18.0，现有脚本 3 轮测量的初始化保留堆增量：lazy 的 scalar48 为 3.99 MiB、nested32 为 7.06 MiB、nested2 为 4.63 MiB。此前记录分别为 4.80、8.47、6.25 MiB；这是跨次运行的趋势比较，不是受控 A/B 或峰值内存结论。完整查询仍需物化旧数据，不能保证所有场景比即时快照更省内存。

## 当前实现：节点级延迟快照（2026-09-22）

以下旧章节保留阶段性测量记录；当前追踪边界以本节和 `docs/guide/faq.md` 为准。

- 基本类型及显式声明 `model` / `childType` 的模型树初始化只建立节点与保存点关系，不生成完整 DTO 快照。
- 首次修改只保存该节点对应 key 的旧值，后续写入不覆盖；不会向祖先通知深复制。
- 模型数组、Record、RecordArray 的容器由 Proxy 拦截结构修改，包括索引、删除和 length 截断。
- 查询时重建旧值；推进保存点时按需固定仍被其他保存点引用的旧节点。因此父子模型分别保存不会互相覆盖。
- 初始化/赋值不执行数据深复制或 JSON.stringify 的测试覆盖标准模型树；元数据初始化、DTO 转换回调不属于此保证。
- 未声明模型类型的普通对象/数组不追踪内部修改；普通对象引用和普通数组初始化复制规则不变。
- 自定义序列化、访问器、动态列和旧式 WeakMap 保留即时快照兼容路径，不能宣称所有模型初始化都不复制。

## 已实施的低风险优化

- `jsonEqual` 对 string、number、boolean、null、undefined 使用无需构造 JSON 字符串的比较。
  保留 NaN/Infinity 与 null 等价、-0 与 0 等价的原有 JSON 语义。
- 变更检测的空白字符串判断改为正则测试，不再通过 replace 生成字符串副本。
- 对象、函数、Symbol、BigInt 等继续调用原生 JSON.stringify；不缓存对象结果，不对相同对象引用提前返回。
  对象键顺序、getter/toJSON 调用顺序、循环引用与 BigInt 异常保持原路径。
- 未改变 JSON 文本输出 API、快照隔离、状态追踪默认值，也未增加全局配置。

JSON 比较并非通用深比较，参见 [JSON.stringify 语义](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/JSON/stringify)。

## 仍需处理的热点

| 位置 | 成本 | 本轮保留的原因 |
|---|---|---|
| changeTracking/arrayChanges.ts | 主键匹配和 JSON 成员比较双重循环，大数组近似平方增长 | 重复主键取末项、主键方法可覆盖、toJSON 可有副作用；不能无条件建立缓存索引 |
| changeTracking/getChange.ts | getChangedData 也计算主键描述，isChanged 又调用 getChangedData | 跳过描述计算会改变工厂/主键方法调用和某些异常路径，需要专门的兼容方案 |
| tools/modelToSerializableObj.ts | 对象先 cloneDeep；存在转换回调时，拷贝结果可能被弃用 | cloneDeep 可访问 getter；直接删除会改变可观察行为，且无回调字段仍需断开引用 |
| ModelBase.saveChangedData | 序列化 DTO 后再 cloneDeep 保存快照 | 回调结果或 emptyValue 可能指向外部可变对象，不能直接复用 DTO 作快照 |
| ModelBase.getColumns | 变更检测等路径读取/合并元数据 | 继承、动态列及缓存失效契约尚需完善，不能全部改成永久缓存 |

建议后续优先解决数组差异计算：先覆盖自定义主键方法、命名策略、重复主键、getter、
toJSON、循环对象，再设计标准模型快路径和兼容回退，而不是更换比较语义。

## Proxy 追踪与延迟快照（后续重构）

`enableDataState: true` 在构造时返回模型 Proxy；`false` 返回普通实例，
不自动保存快照。配置仍为逐模型默认值和逐实例覆盖，不增加全局开关或公开策略参数。
Proxy traps 在所有实例间共享，状态使用 WeakMap，避免逐实例创建多组拦截函数。

当前实现是 **Proxy 写入拦截 + 兼容快照**，不是全量深层 Proxy 或逐字段补丁日志：

- 声明列均为实例自身的简单数据属性（字符串、数字、布尔、null、undefined），
  且没有序列化回调、动态列、子模型时，保存基准只登记延迟快照。
- 第一次实际赋值、删除、重定义属性、修改原型或冻结之前，保存旧数据；
  `getOriginalData()` 也会物化快照，并保留重复调用的对象身份及可修改行为。
  `getChangedData()` 等原有比较流程读取基准时同样会物化，不是只扫描脏字段。
- 数组、普通对象、子模型、getter、Date/Map、函数及转换回调继续走即时快照。
  子模型按各自配置包装 Proxy，普通对象和数组不包装，保留输入引用关系。
  外部原始引用的修改及 Date/Map 内部修改不会经过模型 Proxy，不能省掉这条回退。
- 快照开关现命名为 `enableSnapshot`，`enableDataState` 是兼容别名。
  关闭时显式 saveChangedData 参数也不能强制保存，不能中途开启 Proxy。
- 不额外暴露内部 raw 目标，不自动绑定方法，保留实例方法的 this 和链式返回值。
  Proxy 本身不能直接交给原生 structuredClone / worker 消息克隆；需要传递
  `getSerializableObject()` 生成且满足结构化克隆要求的 DTO。这是启用 Proxy 的互操作边界。

输入对象在该基准中共享，关闭追踪没有保存副本，不能外推为独立请求的总内存占用。

## 多份模块与快照存储

不要求整个进程只加载一个 ModelBase 副本。每份模块有自己的 Proxy 状态和列计划缓存，
不通过 globalThis 或全局注册表共享版本相关内部结构。

`__CLONE__` 仍为 WeakMap，但新建时使用 SnapshotStore 子类：表内只保存 DTO，
延迟快照保存在所属模块的私有状态中。store.get(instance) 通过所属模块的方法物化快照，
其他模块副本无需识别内部包装对象。未物化时 has(instance) 为 false；get 后才有 DTO 条目。
直接调用 WeakMap.prototype.get 绕过了惰性读取，不是受支持的快照读取方式。

如果已有 __CLONE__ 是旧版普通 WeakMap，或归其他模块副本所有，保存时回退即时快照。
跨副本保存或 mergeModel 写入的明确 DTO 优先于尚未物化的旧基准，不被其覆盖。
snapshotCopies.spec.ts 使用独立模块注册表验证两份当前实现的读取、保存、变更和静态回滚，
并验证普通 WeakMap 的兼容路径。这不是对所有历史版本混用或跨 realm 的兼容承诺。

本轮新增 5 个用例：89 个套件、265 个测试通过，保留 3 个已有 todo。

## 初始化与保存快照：消除重复复制

优化目标调整为初始化、赋值及快照保存的成本，变更查询仍按需比较，不增加深层 Proxy。
内置保存流程没有 JSON.stringify；此前成本主要来自字段序列化 cloneDeep 后，再对 DTO
整体 cloneDeep。普通数组输入还有独立的初始化复制，用于维持原有输入引用隔离。

新增内部 SnapshotCopy，在单次序列化中记录已经独立复制的普通对象/数组，以及由这些值
构建的 DTO 容器。保存时直接复用这些内部结果，避免重复构建同一棵普通数据树。
回调返回的外部对象仍需复制；访问器、自定义构造函数、Date/Map/Set/Buffer 等特殊对象
保留兼容路径。公开 getSerializableObject 的返回值及回调引用语义不变。
不存在待生成快照时，Proxy 写入直接转发，跳过额外的属性描述符与相等性检查。

还原时先隔离原始快照，避免普通对象还原后与保存点共享引用、随后修改污染快照。
这项复制只发生在回滚操作，而不是每次字段赋值。
