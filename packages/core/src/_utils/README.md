# 核心内部模块

此目录是内部实现，不通过 `src/index.ts` 新增公开 API。
拆分以职责为单位，不为每个小函数建立独立文件。

```text
_utils/
├── ModelBaseUtil.ts          兼容入口：模型数据操作
├── ChangedModelUtil.ts       兼容入口：变更检测
├── deepCopy.ts               旧式拷贝语义，供兼容路径使用
├── jsonEqual.ts              JSON 语义比较：基础类型快路径，复杂值原生回退
├── columnRegistry.ts         本类列注册、继承解析、注册驱动缓存失效及快照列标记
├── mapping/
│   ├── applyDto.ts           字段筛选、显式操作调度、快照保存
│   ├── dtoValue.ts           DTO 名称/别名查找及反序列化回调
│   ├── defaults.ts           默认值工厂与自动创建默认值
│   ├── childField.ts         嵌套模型及集合创建
│   └── updateField.ts        普通字段、主键数组与 foreign 更新
└── changeTracking/
    ├── proxyState.ts         模型/集合代理、节点旧值日志、独立保存点与延迟物化
    ├── snapshotCopy.ts       保存期间的 DTO 所有权标记，避免重复复制已隔离的普通对象
    ├── getChange.ts          字段差异聚合、动作描述和分组处理
    ├── fieldChange.ts        空值判断、变更分类、创建/删除描述符
    └── arrayChanges.ts       主键数组的增删改及未变更项比较
```

## 依赖约定

- `ModelBase` 继续使用两个兼容入口，原有直接导入路径保持可用。
- `applyDto` 依赖具体字段处理模块；字段处理模块不反向导入 `applyDto` 或兼容入口。
- `getChange` 调用 `fieldChange` 和 `arrayChanges`，规则模块不反向依赖聚合模块。
- 新模块直接导入具体文件，不增加目录级 `index.ts`，避免无关模块被一起加载。
- 仅用于类型的 `ModelBase` 引用使用 `import type`，不额外引入运行时类依赖。
- `childField` 仍复用原集合转换函数；已有创建/转换链路并非完全无环，不能在模块顶层执行模型创建。

## 兼容边界

### 列结构与缓存

- `Column`（两种装饰器语法）、`ColumnDefine` 统一登记本类声明；动态工厂生成的类仍是静态结构类。
- 类缓存通常 O(1) 命中。注册时递增同一 JS realm 中共享的数字时钟，下一次读取才检查父计划；无关注册不重建计划。
- 时钟通过带版本的 `Symbol.for` 共享给多份包副本，只存数字，不保存构造器、实例或配置。类定义及缓存保存在本类元数据上，无反向子类强引用列表。
- 子类同名列完整覆盖父列，新增父列可在下一次解析时传播至已缓存的后代；直接修改内部元数据不是受支持的注册入口。
- 内部通过 `getColumnsCached()` 统一分流；`columnsInValue` 和重写的 `getColumns()` 实时计算。公开 `getColumns()`、`getPrimaryKey()` 继续提供配置副本。
- 注册不调用实例的 `saveChangedData()`。旧延迟保存点固定保存时的列规则；新保存点使用新规则。
- 追加字段与“重命名已有字段、改变转换规则”不同：后者不提供历史 DTO 自动迁移，业务应显式安排新保存点。不能把旧列规则固定理解为支持任意结构迁移。

### 数据与快照

保留公共 API、回调顺序和配置优先级。受支持字段的保存点仍代表 saveChangedData 调用时的数据。
普通初始化只建立节点及保存点关系，不克隆模型数据；字段首次修改才分配本节点旧值日志。
父节点引用子节点保存点，不在每次子节点写入时通知祖先或复制整棵树。
推进保存点时按需固定旧保存点，避免子模型单独保存破坏祖先的旧数据。
`__CLONE__` 使用 WeakMap 子类 SnapshotStore，只保存实际 DTO；延迟状态留在模块私有
WeakMap 中，读取 store.get(instance) 时由所属模块物化。不要绕过 get 直接调用
WeakMap.prototype.get：未物化时底层表还没有条目。旧版普通 WeakMap 使用即时快照。
未声明 childType/model 的对象、数组不新增内部代理或自动还原承诺。
访问器、自定义序列化和动态列保留即时快照；具体边界及内存测量见 `../../PERFORMANCE.md`。
普通对象/数组快照通过一次字段复制获得独立数据，确认安全后不再整体复制一遍。
回调返回值、访问器与特殊对象继续保留必要的兼容复制。所有权标记只活跃于一次保存，
不能跨模型或跨保存点复用；公开 DTO 序列化仍保持原引用语义。
`deepCopy` 不等价于 `cloneDeep`，保留旧行为，不借拆分替换它。
默认值、输入/输出过滤和变更过滤有各自历史规则，不为共享代码而强行合并。

相关测试：`internalModuleCompatibility.spec.ts` 检查兼容入口导出、加载顺序、
包入口不暴露内部函数，以及直接调用入口的快照语义。
初始化、更新、变更追踪、合并和序列化兼容测试负责验证运行行为。

## 流程与规则的边界

- DTO 遍历接收明确的字段操作函数，不使用字符串模式在字段内部切换创建和更新。
  初始化允许补默认值；更新只处理有值字段。两者不能因共享遍历而合并语义。
- 字段筛选必须早于 DTO 读取，避免触发被排除字段的 getter 和转换回调。
- 变更规则区分 CREATE、DELETE、UPDATE、UNCHANGED、IGNORED。
  UNCHANGED 仍可能生成数组的 noChange 描述，不等于可以直接跳过；IGNORED 不生成该字段的描述。
- 删除判定优先于 ignoreEmpty，保持历史行为。分组过滤仍在变更聚合后执行。
- 不引入可配置的策略注册表、额外基类或全局配置；操作函数和小型规则模块已经足够表达当前需求。
- JSON 比较不能直接替换为深比较或对象引用比较；性能基准和保留语义见 `../../PERFORMANCE.md`。
